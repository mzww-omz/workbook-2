# 試験（Exam）

試験は、学習範囲と評価の文脈をまとめて保持する永続的な概念です。学校・学年・
学期・教育機関を前提にせず、問題集・資格・語学・個人学習のいずれにも使えます。
試験は問題を複製せず、条件だけを保存します。条件はセッション開始時と統計表示時に
現在の教材一覧から解決されます。

Workbook 2.5では、より一般的な `Goal` が同じScopeとPlannerを使います。既存Examは
Goal一覧に読み取り専用で適合表示され、模試だけがExam固有の機能として残ります。
Examの行・模試結果・SessionはGoal追加のために移行・複製されません。

## 永続化

- `exams` に試験名、任意の説明、任意の目標日、任意の目標スコア、1日の学習可能時間
  (`daily_minutes`)、スコープJSON、作成・更新日時、任意のアーカイブ日時を保存する。
- `sessions.exam_id` で通常の復習・練習・計画セッションを試験へ紐付ける。
- `sessions.time_limit_seconds` に模試の制限時間を保存する。
- `mock_answers` に模試の回答を `attempts` やFSRSとは分離して保存する。
- `mock_results` に提出済み模試の集計をセッションごとに1件保存する。

schema v5 で `exams.daily_minutes` を追加する。schema v8 で `goals` と `sessions.goal_id`
を追加する。更新は前方のみで、変更前に `pre-migration-v<from>-*.sqlite` の安全用
バックアップを作成する。

## Goal

Goalは試験より一般的な目標で、期限のない個人学習にも使う。

- 名前、Scope、任意の期限、任意の目標スコア、1日の学習時間、アーカイブ状態
- 今日の計画はExamと同じ `plan_exam` を使う
- `sessions.goal_id` でGoal別の今日の学習時間を差し引く
- 既存Examは `Goal::from_exam` でGoal一覧に適合表示する。Examデータは複製しない
- Goal削除は教材・Attempt・FSRS状態を削除しない。Exam由来の削除はExam削除と同じ
- Topic別統計は実測のみ: 対象、学習済み、未学習、復習期限、苦手、回答数、初回正答率
- 習得率・合否予測は表示しない

## スコープの意味

```text
scope =  (グループ1 OR グループ2 OR ... OR 個別問題)
         AND NOT (除外問題 OR 除外Workbook OR 除外タグ OR 除外Topic)

グループ = (workbook_ids に含まれる、または workbook_ids が空)
            AND (tags に含まれる、または tags が空)
            AND (topics に含まれる、または topics が空)
```

- 同じ条件内の複数の値は OR。
- 1つのグループ内の条件どうしは AND。
- 複数グループと `include_questions` は OR。
- 除外は包含の後に適用する。
- 重複は `(workbook_id, question_id)` で除去し、決定的な順序に並べる。
- 空のスコープは「すべて」ではなく「0問」を意味する。保存には少なくとも1つの
  包含条件が必要。
- タグはWorkbook JSONのWorkbook単位 `tags` を指す。
- Topicは `topics` / `question_topics` の安定ID。親Topicを選ぶと子孫も解決対象になる。
- 存在しないWorkbook・問題・Topicへの参照は無視する。
- 新しくインポートされた問題が条件に一致すれば、次回のセッション開始時から対象に
  なる。進行中のセッションは開始時に固定した `session_items` を維持する。

## 学習モード

### 計画（Plan）

「今日の学習を始める」で、期限・1日の学習時間・進捗から今日の出題を自動選択する。
専用の記憶モデルやスコアは作らず、既存FSRSと通常の Attempt / Session を共有する。

- 期限は目標日の属する学習日（午前4時境界、設定タイムゾーン）で判定する。
- 今日使える時間は `daily_minutes` から、同じ学習日にその試験で回答済みの時間を引く。
- 未学習は1日の新規上限（設定 `new_limit`）の残りまで。上限超過分は他の学習へ回す。
- FSRSの期限が来た問題、誤答・lapse・高difficultyの苦手問題、試験日時点の想起確率が
  低い問題を優先する。期限が試験後でも、想起確率が低ければ前倒し候補になる。
  前倒しでも保存済みFSRS状態を直接書き換えず、通常のレビューとして記録して
  モデルに次の状態を計算させる。
- 未学習は単元（Workbook + Note）単位でまとめる。既習は単元と問題形式が連続しない
  ように混合する。単元情報がない場合は通常の優先順にフォールバックする。
- 時間配分は固定の教科ローテーションではない。Workbookごとの未学習・期限・苦手の
  必要量と未着手の分野を加味し、短時間なら少数の分野へ集中する。
- 所要時間は回答履歴の平均を使い、なければ問題形式ごとの初期値を使う。
- 期限までの学習可能時間で範囲全体の初回学習が収まらない場合は、収まると偽らず
  不足を表示する。休んだ日を翌日にまとめて強制しない。計画は毎回現在のDBから作る。

### 復習（Review）

- 既存のFSRS-7スケジューラ、午前4時の学習日、Learn Ahead、兄弟問題の抑制、
  Noteの初回説明ルールをそのまま使う。
- 現在スコープに含まれ、期限が到来している問題（またはLearn Ahead 20分以内の
  短期カード）だけを選ぶ。
- FSRS状態は問題自身の通常状態であり、試験用の別状態は作らない。試験の復習と
  通常の復習は同じ状態を共有する。

### 練習（Practice）

- 戦略: すべて、ランダム、未学習（FSRS状態なし）、以前に誤答（誤答Attemptあり）、
  苦手（lapseあり、difficulty 7以上、または誤答Attemptあり）。
- 問題数を任意で指定できる。
- 回答は練習統計用に `attempts` へ保存するが、FSRSの列は書かない。スケジューラを
  呼び出さない。

### 模試（Mock）

- セッション開始時に問題集合を固定する。
- 問題数、制限時間、固定順・ランダム順を指定できる。
- スキップ、進捗表示、途中提出、最後の提出に対応する。
- 回答は `mock_answers` へ保存し、FSRSを一切変更しない。
- 正誤は通常問題と同じ決定的採点を使う。主観問題や採点不能な形式は
  `correct = NULL` とし、UIでは「採点なし」と表示する。不正解として黙って扱わない。
- `得点 = 正解 / (正解 + 不正解)`。未回答と採点なしは分母に含めない。採点可能な
  回答が1件もない場合は `null` とし、0点を捏造しない。

## 統計

- `total`: 現在スコープに一致する問題数。
- `studied`: FSRS状態（`review_states`）が保存されているスコープ内問題数。
- `unstudied`: `total - studied`。
- `due`: 保存済みFSRSの `due_at` が現在以前のスコープ内問題数。
- `weak`: lapseあり、difficulty 7以上、または誤答Attemptありのスコープ内問題数。
- `coverage`: `studied / total`。スコープが空なら `null`。カバレッジは正答率でも
  期待保持率でもない。
- 計画: 今日の選択数、未学習/復習期限/苦手/試験前確認の内訳、推定所要時間、
  Workbook別配分、期限までの不足時間。推定得点や合否予測は表示しない。
- 練習成績: この試験のPracticeセッションに属する `attempts` の集計。
- 模試履歴: `mock_results` に保存された提出済み集計。

スコープを広げるとカバレッジはすぐ下がる。これは想定どおりで、学習履歴は削除
されない。

## データ保護

- 試験の削除は確認を必要とし、削除前にバックアップを作成する。その試験の学習中は
  削除できない。
- 試験を削除してもWorkbook・問題・Note・FSRS状態は削除しない。模試セッションと
  模試結果は削除し、Review/Plan/Practiceセッションは履歴を残したまま `exam_id` を
  `NULL` にする。
- 履歴リセットはセッション、Attempt、模試回答・結果、FSRS状態を削除するが、
  試験そのものは残す。
